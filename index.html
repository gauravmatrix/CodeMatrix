About

I'm a backend-leaning software developer who likes turning a problem into a working system — from the database schema up through the API to whatever's calling it.

Most of my work sits in Python (Django) and Java (Spring Boot), building REST APIs, authentication flows, and database-driven features for full-stack web applications. I'm comfortable moving across the stack when a project needs it — from the interface a user touches to the query that answers their request.

Lately I've been going deeper on system design and database optimization: thinking about how a service should be structured before I write it, not just after something breaks. I learn best by building real projects end to end, which is why most of what's below started as something I wanted to solve rather than a tutorial I followed.
